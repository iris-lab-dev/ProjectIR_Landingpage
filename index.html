04 / Fast transfer

필요한 물품을,
필요한 곳까지 빠르게.

빠른 전송은 단순히 물품을 옮기는 요청만이 아닙니다. 직접 가진 물품을 전달할 수도 있고, 필요한 물품을 수령하거나 구매한 뒤 원하는 장소까지 전송할 수도 있습니다.

TYPE 01

직접 전송

이미 가지고 있는 물품을 원하는 위치로 빠르게 전달해야 할 때.

TYPE 02

수령 후 전송

매장이나 지정 장소에서 물품을 받은 뒤 원하는 위치로 전달해야 할 때.

TYPE 03

구매 후 전송

장보기나 오픈런처럼 필요한 물품을 구매·확보한 뒤 전달해야 할 때.
